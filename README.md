# Virtual Broadcast Production Assistant & Smart Stories

This repository serves as a landing place for example open-source implementations referenced by the industry for the IBC Accelerators project **Smart Stories: Agentic Production Ecosystem** (2026).

## About the Project

This project has evolved from the 2025 IBC Accelerator Project: [AI Assistance Agents for Live Production](https://show.ibc.org/accelerator-project-ai-assistance-agents-live-production).

For 2026, the project is an incubator project called **Smart Stories**. It revolves around a **Story Object Model (SOM)**, a proposed standard for agents and agentic workflows to understand a news story from inception to archive.

Learn more about the 2026 Incubator Project: [Smart Stories: Agentic Production Ecosystem](https://show.ibc.org/accelerator-project-incubator-2026-smart-stories-agentic-production-ecosystem).
